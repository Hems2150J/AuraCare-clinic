# 🏥 AuraCare Clinic & Medical Center

A modern, responsive, full-featured healthcare and medical center web application built with React, Vite, and Tailwind CSS.

---

## ✨ Features

- **Dynamic Homepage**: Hero section, trust metrics, quick appointment booking, featured doctors, services showcase, why choose us, testimonials carousel, and newsletter.
- **Doctor Directory & Profiles**: Filterable doctor profiles by specialty, availability, and detailed doctor profile modals.
- **Appointment Booking Flow**: Multi-step booking flow with date, time-slot selection, and emergency fast-track modal.
- **Telehealth & Virtual Consultations**: Virtual video consultation room interface and digital prescription generator/download.
- **Online Pharmacy & Healthcare Shop**: Product catalog with search, category filtering, shopping cart drawer, checkout flow, and order tracking.
- **Patient Portal & Records**: Interactive dashboard for patient appointments, medical history, lab results, and prescriptions.
- **Admin Dashboard**: Clinic overview, patient metrics, appointment management, and doctor schedules.
- **Interactive Map & Contact**: Leaflet-powered clinic locator, working contact form, and FAQ accordion.
- **Patient Reviews & Ratings**: Community ratings breakdown, reviews list with filtering, and write-a-review modal.
- **Live Chat Assistant**: Floating healthcare assistant widget for instant inquiries.
- **Smooth Animations & Interactions**: Lenis smooth scrolling, GSAP animations, Lucide icons, and confetti celebrations.

---

## 🛠️ Tech Stack

- **Frontend Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Maps**: [Leaflet](https://leafletjs.com/) & [React-Leaflet](https://react-leaflet.js.org/)
- **Animations**: [GSAP](https://greensock.com/gsap/) & [Lenis](https://lenis.darkroom.engineering/)
- **Utility**: [Tailwind Merge](https://github.com/dcastil/tailwind-merge), [clsx](https://github.com/lukeed/clsx), [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine (v18 or higher recommended).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Hems2150J/AuraCare-clinic.git
   cd AuraCare-clinic
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

---

## 📦 Build for Production

```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```
